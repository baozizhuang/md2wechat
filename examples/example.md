## 表格

| 主题 | 适合账号 | 标题样式 |
|---|---|---|
| default | 科普 / 技术 | 蓝色竖条 |
| warm | 生活 / 亲子 | 橙色竖条 |
| ink | 深度长文 | 黑色下划线 |

## 代码块

```python
from md2wechat import convert

html = convert("# 你好，公众号", theme="warm")
print(html)
```
